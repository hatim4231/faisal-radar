# 📡 رادار طريقة فيصل

برنامج يمسح الأسهم الأمريكية الصغيرة (Penny / Small caps) كل يوم، ويطبّق عليها شروط طريقة فيصل، ويطلع لك **صفحة ويب** فيها:

- **الأسهم اللي طابقت الطريقة** (✅ مطابق / 🟡 قريب / 👀 رادار) مع نسبة جاهزية من 100.
- **كم باقي لكل سهم**: مثلاً "يحتاج ينزل 8.4% ليدخل منطقة الطلب 1.52 – 1.67" أو "باقي 6 نقاط RSI لمنطقة 23-27" أو "باقي 4% لاستعادة MA20".
- **خطة فيصل لكل سهم**: الدعم الحقيقي، منطقة الطلب، 3 طلبات Limit، وقف الخسارة تحت القاع، الهدف الأول، والأهداف الأربعة (كل هدف 25%).
- شارت يومي فيه الدعم ومنطقة الطلب والوقف والأهداف وMA20/MA50.
- تبويب **أسهم الزخم** لليوم (RVOL، فجوة الافتتاح، الفواب، الفلووت، الأخبار).

## التشغيل (مرة وحدة)

1. نزّل Python من https://www.python.org/downloads/ (على ويندوز فعّل خيار **Add Python to PATH**).
2. فك ضغط المجلد.
3. **ويندوز:** دبل كلك على `تشغيل_ويندوز.bat`
   **ماك:** دبل كلك على `تشغيل_ماك.command` (أول مرة: كلك يمين ← Open)
4. يفتح لك المتصفح على `http://127.0.0.1:8765`. أول مسح ياخذ 5-15 دقيقة، وبعدها يعيد المسح كل 30 دقيقة، وفيه زر **🔄 تحديث المسح**.

### أوامر إضافية (من الترمنال داخل المجلد)

```bash
python scanner.py
```
مسح كامل مرة وحدة، ويفتح التقرير كملف `output/faisal_report.html` (وفيه كمان `output/latest.csv` يفتح في Excel).

```bash
python scanner.py --watchlist watchlist_faisal.txt
```
فحص قائمتك أنت فقط (سهم بكل سطر). الأسهم هنا تظهر حتى لو ما اجتازت الفلتر.

```bash
python scanner.py --tickers BJDX,GDHG,LFS
```

```bash
python scanner.py --demo
```
تقرير تجريبي ببيانات وهمية.

## وش الشروط اللي يطبقها؟ (من ملفات فيصل)

**فلتر القائمة (Finviz):** ناسداك · السعر تحت 5$ · قيمة سوقية تحت 300M · فلووت تحت 50M · متوسط فوليوم فوق 100K.

**جاهزية سهم الارتكاز (100 نقطة):**

| الشرط | النقاط | كيف ينحسب |
|---|---|---|
| قريب من دعم حقيقي | 20 | قيعان مكررة آخر 6 شهور؛ السعر ضمن 10% فوق الدعم |
| RSI مضغوط 23-27 | 15 | RSI يومي 14؛ أو انضغط آخر 10 أيام وهو الحين تحت 40 |
| فشل الهبوط | 15 | ما كسر أدنى قاع 5 جلسات، أو سحب سيولة تحت الدعم ثم استرداد |
| شمعة إيجابية | 10 | Hammer / Engulfing / ذيل سفلي عند الدعم |
| MACD يتحسن | 10 | تقاطع إيجابي أو الهيستوجرام يتحسن 3 أيام |
| الفوليوم يؤكد | 10 | فوليوم أيام الصعود أكبر من الهبوط، أو فوليوم البيع يجف |
| المتوسطات 20/30/50 | 10 | تحتها = ضغط، استعادة MA20 = تحسن |
| مساحة صعود | 10 | أول مقاومة / شمعة ساقطة / فجوة فوق بـ 20%+ |

**تعديلات السلوك:** Former Runner (+5) · فلووت تحت 5M (+3) · نموذج W (+3/+4) · قيعان أعلى (+3) · شموع قروبات (−10) · صعد 50%+ من القاع = لا تطارد (−15) · شورت مرتفع (−8) · تقسيم عكسي قبل أقل من 20 يوم (−3، قاعدة الـ 20-50 يوم) · كسر الدعم وبقي تحته (−10) · قاع جديد على فريم 4 ساعات (−5).

**الحالة:** ✅ مطابق = 75%+ مع تحقق الدعم والثبات وRSI مضغوط · 🟡 قريب = 60%+ وضمن 20% من الدعم وRSI تحت 40 · 👀 رادار = 40%+.

كل الأرقام تقدر تعدلها من `config.json`.

## وش ما يقدر البرنامج يسويه (لازم تشوفه بعينك)

- **شمعة المضارب مقابل شمعة القروب** على ويبل (سيولة الشمعة بالدولار لحظياً).
- **Level 2** والطلبات الوهمية.
- **الشورت المتاح** الحقيقي (iBorrowDesk / المنصة). الرقم في البرنامج هو Short Interest الرسمي من ياهو.
- قراءة الخبر نفسه هل هو إيجابي أو سلبي (البرنامج يجيب العناوين فقط).
